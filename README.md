# Kreuzmeyer-Wasche-Hebe-M-hle

"If we can't fix it we're doing the work by hand." - the farmer's predicament and a saying in every language through the ages.

Background;

The apple harvest is in, press now or wait a year. We moved site, the new place didn't have a three phase socket at the wall. Getting one installed would take months. We've attempted doing the work with a smaller mill and a large shovel. We're able to find an inverter (a very well used word - in this case it's a box that turns single phase into three phase) nearby and buy it. UK three phase 16A plug has four conductors, EU three phase 16A plug has five conductors, including Neutral. The Kreuzmeyer machine uses the neutral for the control system. I was apparently not the first person to deal with the farmer's predicament. This machine had taken a fall at some point and the VFD had been replaced. there were also some loose, clearly original wires. A circuit diagram was sitting inside the closed control box. (Halleluja). Kreuzmeyer are also very helpful in supplying manual etc. Great company, great machine, really enjoyed working on it. I established that it would be possible to add a separate L1 and N to run the control system and lift motor - and to run the three phase mill motor from the inverter. Great plan, now let's execute it in a dark corner, inside a cramped box with limited tools. The main consideration is now safety. This is not safe.

The grossest hazard is the 400V between two phases - it will kill you, no warning, no sound, no tingle, just game over. 230V is still no joke.

The first control is that I have the plugs in front of me, I can see, touch, check that they are in fact unplugged - I know the state of the machine.

I do however have to work on the machine with the power on. This is necessary to check the voltage against the schematic, do fault finding on the control system. I install an inline RCD on the L1-N plug and do this with the three phase line unplugged and where I can see it. This will not help me if I touch L and N at the same time so fault finding / mapping real wiring to plan is done with one hand and a neon tube screwdriver (limited tools available).

The actual danger is making the mistake of touching one or more live phases. I'm taking a very "if you're not sure, stop, have a cup of tea" type of approach to this. The actual change that needs to be made is not complicated - but under the conditions it is very frustrating, somewhat frightening, and the risks are real - it's dangerous and it costs a lot of money if you break it. Slow and sure and steady wins here.

The phase separation was successful. It turned out that the new VFD had been installed incorrectly. I looked up the data sheet, rewired the device, checked that the machine worked as expected and annotated the circuit diagram.

The machine is very well designed, works brilliantly, has a huge throughput, is extremely reliable. We got tons of apples milled. The machine was later sold.
